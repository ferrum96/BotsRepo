# Астробот

Telegram-бот: натальная карта, гороскоп дня, таро, ИИ-астролог, подписка Pro через Telegram Stars и Mini App.

## Запуск

```bash
cd fl_5522329
cp .env.example .env
# вписать BOT_TOKEN и OPENROUTER_API_KEY
docker compose up --build
```

Бот слушает long polling. HTTP API и собранный Mini App — на [http://127.0.0.1:8080](http://127.0.0.1:8080). Postgres с хоста: `127.0.0.1:55432`, Redis: `127.0.0.1:56379`.

Кнопка Mini App в чате появляется, только если `WEBAPP_URL` — публичный HTTPS. Без него дату рождения можно ввести командой `/profile`.

Локальная вёрстка Mini App:

```bash
cd miniapp
npm install
npm run dev
```

Для запросов вне Telegram включи `ALLOW_INSECURE_INIT_DATA=true` и заголовок `X-Dev-User-Id`. В проде флаг должен быть выключен.

## Команды


| Команда           | Кто   | Что делает                          |
| ----------------- | ----- | ----------------------------------- |
| `/start`          | все   | Дисклеймер при первом запуске, меню |
| `/profile`        | все   | Дата, время, место рождения         |
| `/horoscope`      | карта | Гороскоп на сегодня по знаку Солнца |
| `/tarot`          | карта | 3 карты. Free: 1 раз в сутки        |
| текст             | карта | Вопрос астрологу. Free: 1 в сутки   |
| `/pro`            | все   | Счёт Telegram Stars, 299 ₽/мес      |
| `/synastry @user` | Pro   | Совместимость двух карт             |
| `/monthly`        | Pro   | Прогноз на месяц                    |
| `/invite`         | все   | Реферальная ссылка                  |


Счётчики Free живут в Redis и сбрасываются в 00:00 Europe/Moscow. Зеркало пишется в `daily_limits`. Pro лимиты не расходует.

Оплата в Telegram идёт в Stars (валюта `XTR`), не в рублях. `PRO_PRICE_STARS` — сколько звёзд списывать за месяц, который в продукте стоит 299 ₽. `PRO_PERIOD_DAYS` — на сколько дней включается Pro после оплаты. Значение `30` значит один оплаченный период на 30 дней. Если Pro ещё действует, новые дни прибавляются к концу текущего срока, а не с сегодня. Повтор того же платежа срок второй раз не продлевает. Допустимый диапазон: от 1 до 366. После правки `.env` контейнер бота нужно пересоздать.

## Гороскоп дня

`/horoscope` и кнопка «Гороскоп» пишут прогноз на сегодня для знака Солнца из сохранённой карты. Сначала нужен `/profile`.

В чат уходит цельный текст без ссылок, до 15 предложений:

1. Заголовок: дата и знак («на 28 сентября для Девы»).
2. Общий фон дня: тон и 1–2 аспекта.
3. Работа, финансы, отношения, самочувствие. В каждом блоке 1–2 предложения.
4. Совет: что сделать и чего избегать.

Данные собираются без отдельного ключа гороскопа. Sigastra (`SIGASTRA_BASE_URL`) отдаёт три вещи: оценки дня по отношениям, работе и энергии, аспекты с орбом, фазу и знак Луны. Английский текст источника в модель не попадает. Планеты, аспекты и фазы переводятся словарём.

Дальше ChromaDB ищет 5 фрагментов в локальной базе `app/horoscope/knowledge.py`: аспекты по сферам жизни, особенности знака, Луна и короткие образцы стиля. Индекс лежит в `data/chroma`. При первом старте контейнер скачивает модель эмбеддингов.

В модель уходит короткий промпт: эти поля, пять фрагментов и пример тона. Ответ идёт через тот же клиент, что и чат: `OPENROUTER_API_KEY`, `OPENROUTER_BASE_URL`, `OPENROUTER_MODEL`. Для Gemini укажите совместимый адрес и имя модели. Если ответ оборвался, бот запрашивает его ещё раз и не присылает обрезок.

## Архитектура

Один процесс Python. `python -m app.main` поднимает uvicorn и FastAPI. В lifespan тот же процесс либо поллит Telegram, либо принимает `POST /webhook`. Отдельного воркера бота нет.

```
Telegram  →  aiogram (polling или /webhook)
Mini App  →  /api/*  (init data)
                │
                ├─ PostgreSQL   пользователи, карты, подписки, история, зеркало лимитов
                ├─ Redis        FSM диалога и счётчики Free
                ├─ ChromaDB     индекс базы гороскопа, каталог data/chroma
                ├─ pyswisseph   натал, транзиты, синастрия, месяц
                ├─ Sigastra     оценки дня, аспекты, Луна (только /horoscope)
                └─ /chat/completions   чат и текст гороскопа
```

В Docker у сервиса `bot` свои `DATABASE_URL` и `REDIS_URL`: хосты `postgres` и `redis`, не порты с машины. Том есть у Postgres и у `./data/chroma`. У Redis тома нет: пересоздание контейнера обнуляет лимиты и незавершённый `/profile`. Карты в Postgres остаются.

Старт контейнера: `alembic upgrade head`, прогрев Chroma, затем `python -m app.main`. Если `WEBHOOK_URL` пуст, перед поллингом вызывается `delete_webhook`.

### Входы


| Путь                                                                                           | Кто ходит                                   |
| ---------------------------------------------------------------------------------------------- | ------------------------------------------- |
| long polling или `POST /webhook`                                                               | Telegram                                    |
| `GET /health`                                                                                  | проверка живости                            |
| `GET /api/geocode`, `POST /api/profile`, `GET /api/me`, `POST /api/tarot`, `POST /api/invoice` | Mini App                                    |
| `/`                                                                                            | собранный `miniapp/dist`, если каталог есть |


Mini App в чате открывается только при публичном HTTPS в `WEBAPP_URL`. Запросы API проверяют `X-Telegram-Init-Data`. Локально без Telegram: `ALLOW_INSECURE_INIT_DATA=true` и заголовок `X-Dev-User-Id`.

### Бот

Роутеры по порядку: `start`, `billing`, `readings`, `profile`, `chat`. Обычный текст без команды доходит до `chat` последним.

На каждом апдейте три middleware: сессия БД, загрузка пользователя, дисклеймер до принятия. `TelegramBadRequest` в чат второй раз не пишется. Прочая ошибка хендлера отвечает «Не получилось обработать запрос».

Состояние формы `/profile` лежит в Redis (FSM aiogram).

### Откуда берётся текст


| Действие                | Расчёт                                                                                                                                       |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `/profile`, Mini App    | pyswisseph пишет `natal_charts`. Знак Солнца сверяется с flatlib, при расхождении остаётся swisseph                                          |
| `/horoscope`            | знак Солнца из карты → Sigastra → словарь → 5 фрагментов Chroma → модель. Ссылки из ответа вырезаются                                        |
| текст без команды       | натал, текущие транзиты и последние `CHAT_HISTORY_LIMIT` сообщений. Sigastra и таро в этот промпт не входят                                  |
| `/tarot`                | локальная колода, без модели. Free: `FREE_TAROT_PER_DAY`                                                                                     |
| `/monthly`, `/synastry` | swisseph, только Pro                                                                                                                         |
| `/pro`                  | счёт Stars (`XTR`) на `PRO_PRICE_STARS`. Срок в `subscriptions` — `PRO_PERIOD_DAYS`. Подпись счёта в чате зафиксирована как «Pro на 30 дней» |


Free-счётчик: ключ Redis `limit:{user_id}:{дата МСК}:tarot` или `ai`, живёт до 00:00 Europe/Moscow. Зеркало пишется в `daily_limits`. Pro ключ не увеличивает.

### Таблицы


| Таблица         | Что хранит                                 |
| --------------- | ------------------------------------------ |
| `users`         | telegram id, дисклеймер, кто пригласил     |
| `natal_charts`  | дата, место, знаки, планеты, дома, аспекты |
| `subscriptions` | период Pro, статус, `charge_id` платежа    |
| `daily_limits`  | зеркало суточных счётчиков                 |
| `chat_history`  | реплики ИИ-чата                            |


Рядом в compose крутится `backup-cron`: `pg_dump` в 03:15 UTC, 14 архивов в `./backups`.

## Стек

Python 3.11, aiogram 3, FastAPI, PostgreSQL, Redis, pyswisseph (дома, планеты, транзиты, прогрессии). flatlib 0.2.3 ставится отдельно с `--no-deps`: пакет на PyPI жёстко требует `pyswisseph==2.08.00-1`, а расчёт идёт на актуальном pyswisseph. Если flatlib импортируется, знак Солнца сверяется с ним; при расхождении остаётся swisseph. Если файлов Swiss Ephemeris нет, планеты считаются встроенным Moshier. ИИ-чат и текст гороскопа идут через OpenAI-совместимый `/chat/completions` (`OPENROUTER_BASE_URL`). Mini App: React и `@telegram-apps/sdk-react`. Гороскоп дня дополнительно использует Sigastra и ChromaDB.

## Бэкапы

Сервис `backup-cron` запускает `pg_dump` каждый день в 03:15 UTC, хранит 14 архивов в `./backups`. Ручной запуск: `docker compose run --rm backup`. Пример crontab для хоста: `scripts/crontab.example`.

## Вебхук

Если задан `WEBHOOK_URL` (полный HTTPS, например `https://host/webhook`), процесс не поллит, а принимает `POST /webhook`. `WEBHOOK_SECRET` уходит в Telegram как secret token.
