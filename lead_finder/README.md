# TG Lead Finder

**Находит ваших клиентов в Telegram-чатах с помощью ИИ-агента и оценивает их готовность к покупке.**

---

## Что это такое

Вы указываете Telegram-чаты, где сидит ваша аудитория — и инструмент сам:

- собирает сообщения за нужный период,
- отбирает тех, кто может быть вашим клиентом,
- оценивает каждого по шкале теплоты **0–100** и ставит метку риска фрода,
- выдаёт готовый **HTML-дашборд** с горячими лидами, отсортированными по готовности к покупке.

Подходит для любой ниши: фриланс, услуги, обучение, агентства, продукты.

---

## Как начать — один шаг

> **Откройте папку в Claude Code и напишите: *помогите настроить* — дальше агент проведёт вас по шагам.**

Технических знаний не нужно. Агент сам спросит, что ему нужно, и объяснит каждое действие.

Подробная инструкция по установке и первому запуску: [docs/quickstart.md](docs/quickstart.md)

---

## Воронка установки

1. **Создайте аккаунт Claude** на [claude.ai](https://claude.ai) — бесплатно, пара минут.
2. **Установите Claude Code** — десктопное приложение от Anthropic (macOS / Windows).
3. **Скачайте этот инструмент** с Яндекс.Диска или GitHub и разархивируйте папку.
4. **Откройте папку в Claude Code** и напишите: *помогите настроить*.

Всё остальное сделает агент.

---

## Что вы получаете на выходе

HTML-файл с дашбордом горячих лидов:

- **Балл теплоты (0–100):** насколько человек готов к покупке прямо сейчас.
- **Бэнд:** ❄️ холодный → 🌤 тёплый → ☀️ тёплый → 🔥 горячий → 🌋 очень горячий.
- **Метка риска фрода:** 🟢 чисто / 🟡 проверить вручную / 🔴 не контактировать.
- **Почему такой балл** и **что предложить** — кратко по каждому лиду.

Пример файла с вымышленными данными — в папке [`examples/`](examples/).

## Безопасность

Все ключи, сессии и данные хранятся **только у вас на компьютере**. В Git они не попадают — это прописано в `.gitignore`. Никаких данных на сторонние серверы инструмент не отправляет.
