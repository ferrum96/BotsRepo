# Как пользоваться инструментом

---

## Это не автономная система

TG Lead Finder **не работает сам по себе** в фоне. Каждый новый сбор лидов вы запускаете вручную — когда захотите.

Как это выглядит на практике:

1. Открываете папку проекта в **Claude Code** (десктоп).
2. Пишете агенту: «собери лидов» (или «запусти сбор», «нужны новые лиды»).
3. Агент запускает парсинг, оценивает кандидатов по методике и готовит дашборд.
4. Вы смотрите результат и идёте работать с горячими лидами.

Больше ничего делать не нужно — агент ведёт вас по шагам.

---

## Правила анти-бан: как не попасть в блокировку Telegram

Telegram следит за подозрительной активностью. Если парсить слишком агрессивно — аккаунт могут ограничить. Соблюдайте простые нормы:

| Что делать | Почему |
|---|---|
| **Делайте перерывы между прогонами** — минимум несколько часов | Telegram видит непрерывные запросы как бота |
| **Не запускайте сбор чаще 1–2 раз в день** | Нет смысла и в чатах за час мало что меняется |
| **Глубина сбора — не более 14 дней** | Более старые сообщения — холодные; большая глубина замедляет работу |
| **Используйте отдельный аккаунт** | Если что-то пойдёт не так, основной номер в безопасности |

> Движок сам делает паузы между запросами (автоматическое замедление встроено). Ваша задача — не запускать парсинг слишком часто вручную.

## Шпаргалка команд

Если хотите запускать инструмент напрямую, не через агента:

### Посмотреть список доступных групп
```
python scraper.py --list-groups
```
Выводит все Telegram-группы, в которых состоит ваш аккаунт. Отсюда берёте нужный `username` или `id` для парсинга.

### Собрать сообщения из конкретной группы
```
python scraper.py --group НАЗВАНИЕ_ГРУППЫ
```
Замените `НАЗВАНИЕ_ГРУППЫ` на username чата (например, `myforum`) или его числовой id.

Дополнительные параметры:
```
python scraper.py --group НАЗВАНИЕ_ГРУППЫ --days 7
```
`--days 7` — собрать сообщения только за последние 7 дней (рекомендуется, максимум 14).

### Собрать из нескольких групп сразу
```
python scraper.py --group группа1 --group группа2 --group группа3
```

### Открыть HTML-дашборд с лидами
```
python dashboard.py
```
Генерирует файл `output/dashboard.html` — откройте его в браузере. Лиды отсортированы по горячести: сверху — самые готовые к покупке.

## Типичный рабочий цикл

```
Понедельник утром:
  → Открываю папку в Claude Code
  → Пишу «собери лидов за последние 7 дней»
  → Агент парсит, оценивает, строит дашборд
  → Открываю дашборд → смотрю на 🌋 и 🔥
  → Пишу горячим лидам

Четверг:
  → Повторяю (прошло достаточно времени, новые сообщения накопились)
```

---

## Что делать с результатами

После сбора у вас есть:
- `output/dashboard.html` — горячие лиды с баллами и советами по заходу
- `output/messages_filtered.json` — полный текст всех кандидатов (для ручного изучения)

Горячие лиды (🌋 80–100 и 🔥 60–79) — пишите напрямую. Используйте «Сценарий входа» из дашборда как отправную точку для первого сообщения.

Лиды с 🔴 риском фрода — не трогайте, даже если балл высокий.
